# 小屏 QAM 面板功能清单

对应文件：[plugin/src/QamScreen.tsx](../plugin/src/QamScreen.tsx)

## 全局（所有页签共用）

| 项目 | 说明 | 实现位置 |
| --- | --- | --- |
| 面板尺寸 | `min(460px, calc(100vh - 90px))`，固定高、`overflow: hidden` | `PAGE_H` |
| 页签行 | 询问 / 聊天 / 设置，高 26px，选中高亮 | `tabRow` |
| L1 / R1 翻页 | 两端键帽提示；焦点冒泡 + `SteamClient.Input` 双通道，`bumpOnce` 去重 | `padHint`、`useEffect` |
| 页签记忆 | 模块级 `lastTab`，重开面板回到上次页签 | `lastTab` |
| 会话状态 | `useQamSession()`：状态轮询、WebSocket 流、忙碌/耗时、模型/开关 | `useQamSession` |
| 消息区 | `ChatLog`：气泡、思考链、流式光标、空态文案、选项按钮 | `ChatLog` |
| 断线态 | 无 status 时只显示「连接」卡 + 重试连接 + 打开大屏 | 早退分支 |
| 配置错误态 | `config_error` 时只显示错误卡 + 重试 | 早退分支 |

## 询问页

| 项目 | 说明 | 实现位置 |
| --- | --- | --- |
| 状态行 | 高 16px：昵称状态短句 / 核心状态 + 预设名 + `ip:port` | L1634 |
| 画面静止提示 | 条件出现（`pendingPoke`），带「重新截图」按钮 | L1679 |
| 截屏询问 | 主按钮；忙时原地变「思考中…（Ns）」 | L1732 |
| 截屏翻译 | 次按钮；忙时原地变「思考中…（Ns）」 | L1747 |
| 中断 | 另一格按钮在忙时变「中断」 | L1740 / L1755 |
| 分隔线 | 1px 分隔动作区与消息区 | `dividerStyle` |
| 消息区 | 共用 `ChatLog`，空态文案「还没有对话…」 | L1764 |

| 语音结果 | 追加到已有输入后，不覆盖已打的字 | `useVoiceInput` 回调 |

## 共用组件

| 组件 | 说明 |
| --- | --- |
| `Btn` | 紧凑按钮，统一高度/最小宽度，6 种视觉态（primary / danger / running / done / 普通 / 置灰） |
| `Card` | 设置页卡片：内边距 10×12、左强调条 |
| `StatCell` | 连接卡两列读数单元 |
| `Bubble` | 气泡：我的/她的/系统事件三种对齐与配色 |
| `useVoiceInput` | 语音录音、识别、模型下载 |
| `statusLineFor` | 状态栏短句（待机/忙碌/出错 + 游戏名） |
