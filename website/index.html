Design

设计取舍

几个刻意的选择，让它真的好用。

01

遮罩只盖会动屏幕的那一步

点击、打字、滚动时才显示半透明遮罩，点一下即终止；跑命令、翻文件不遮视线。

02

上下文压缩，而不是丢弃

快满时把旧对话摘要成一条 system 消息，保留目标与偏好，长任务不失忆。

03

为 DeepSeek 前缀缓存让步

历史只追加、旧截图换成标记，让前缀每轮一致，命中硬盘缓存按低价计费。

04

长期记忆是显式教学

只有「记住」时她才记录，没有后台自学噪声，记忆干净可控。

05

Web 与客户端同源

客户端不复制界面，直接加载本地服务，改一处两端同步。

Install

三种安装方式

装完都是同一个目录，任选一条。

① 一行命令（推荐）

curl -sL https://meido.meagames.cn/deckmeido/install.sh | bash

第一次全新安装，之后再跑会问「升级还是卸载」。适合大多数用户。

② Git 源码

git clone https://github.com/Congmeims/deckmeido.git
cd deckmeido && bash install.sh

需要本地源码目录、或想贡献代码时用。

③ 手动下载

在下载区取最新 tar.gz，解压后 bash install.sh。

完全离线、或需要特定版本时用。

FAQ

常见问题

控制类插件是什么？
ydotool（模拟点击和打字）、kdotool（按窗口名聚焦）、espeak-ng（念出回复）。装它们需要 root，安装脚本结尾会问一次；跳过也能用，只是少了「动手」和「开口」的能力。随时补装：bash install.sh install --deps。
SteamOS 更新后点击失灵？
换镜像会冲掉 /usr 下 pacman 装的包，重跑 bash install.sh install --deps 即可。bash install.sh check 能逐个实测哪些真的没了。
升级后聊天记录丢了？
不应该发生——会话存在 server/sessions/，升级不碰。如果确实丢了，多半是有两份后端抢同一端口，跑一次 bash install.sh upgrade 会清理残留进程。
游戏模式下网页打不开？
正常，SteamOS 游戏模式的浏览器不在。用 Decky 插件的 QAM 面板，或切回桌面模式。
装不下、下载很慢？
先在 Deck 上测哪个 pip 源最快：bash install.sh speedtest。
