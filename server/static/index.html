远程连接

从别的设备远程使用这台 Deck：跨屏鼠标把电脑上的鼠标键盘接管到这台机器； Onebot 通道让指定的 QQ 发消息下达指令。两项都只在你明确打开后才生效。

跨屏鼠标（远程接管）

在电脑浏览器里点左下角 DeckMeido logo 就进入接管：鼠标从电脑上消失，出现在这台 Deck 上， 能操作 Steam UI、游戏和这个页面。按 Esc、再点一次 logo，或在 Deck 客户端里点 logo 释放。 开关没开时点 logo，会先把你带到这里的开关上。

安全提示：标题右侧的开关同时就是「允许局域网设备接管」。开启后，局域网内任何已配对设备 都能控制这台机器。只在可信网络里用，用完及时关闭。

对话与语音
控制桌面客户端「语音」按钮的听写：录音在本地完成，整段音频交给后端离线识别，文字只填进输入框、不会自动发送。需要先装 sherpa-onnx 运行时并下载约 250MB 的 SenseVoice 模型；关掉后会释放已加载的识别模型（约 100MB+），语音识别随之停用。
按住右扳机开始录音，松开自动识别并填入输入框；只在客户端窗口激活且语音输入可用时响应，关掉后 R2 不做任何处理。
